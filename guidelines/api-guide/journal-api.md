 Journal 엔티티 구조

  태그 엔티티 (사용자 등록 마스터)

  ┌───────────────┬──────────────────┬──────────────────────────────────────────────────────────────────────────────────────┐
  │    엔티티     │      테이블      │                                      주요 컬럼                                       │
  ├───────────────┼──────────────────┼──────────────────────────────────────────────────────────────────────────────────────┤
  │ ConditionTag  │ condition_tags   │ id, userId(UUID), condition(String), conditionType(ConditionType), isActive, visible │
  ├───────────────┼──────────────────┼──────────────────────────────────────────────────────────────────────────────────────┤
  │ SideEffectTag │ side_effect_tags │ id, userId, sideEffect(String), isActive, visible                                    │
  ├───────────────┼──────────────────┼──────────────────────────────────────────────────────────────────────────────────────┤
  │ TroubleTag    │ trouble_tags     │ id, userId, trouble(String), type(TroubleType), isActive, visible                    │
  ├───────────────┼──────────────────┼──────────────────────────────────────────────────────────────────────────────────────┤
  │ DailyGoal     │ daily_goals      │ id, userId, dailyGoal(String 500), isActive — UK(userId, dailyGoal)                  │
  └───────────────┴──────────────────┴──────────────────────────────────────────────────────────────────────────────────────┘

  로그 엔티티 (날짜별 체크 기록)

  ┌────────────────┬───────────────────┬─────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │     엔티티     │      테이블       │                                                주요 컬럼                                                │
  ├────────────────┼───────────────────┼─────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ ConditionLog   │ condition_logs    │ id, conditionTagId, checkedAt(LocalDateTime)                                                            │
  ├────────────────┼───────────────────┼─────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ SideEffectLog  │ side_effect_logs  │ id, sideEffectTagId, checkedAt                                                                          │
  ├────────────────┼───────────────────┼─────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ TroubleLog     │ trouble_logs      │ id, troubleTagId, checkedAt                                                                             │
  ├────────────────┼───────────────────┼─────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ DailyGoalLog   │ daily_goal_logs   │ id, dailyGoalId, score(0~10), date(LocalDate) — UK(dailyGoalId, date)                                   │
  ├────────────────┼───────────────────┼─────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ DailyStatusLog │ daily_status_logs │ id, userId, sleepHour(Float), sleepQuality, ateBreakfast/Lunch/Dinner(Boolean), date — UK(userId, date) │
  ├────────────────┼───────────────────┼─────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ Memo           │ memos             │ id, userId, journalDate(LocalDate), memo(TEXT) — UK(userId, journalDate)                                │
  └────────────────┴───────────────────┴─────────────────────────────────────────────────────────────────────────────────────────────────────────┘

  열거형

  - ConditionType: UP / DOWN / TIGHT / FOGGY / CALM / USER_INPUT                                                                                                        
  - TroubleType: INATTENTION / HYPERACTIVITY / IMPULSIVITY / TIME_MANAGEMENT / COGNITIVE_ERROR / USER_INPUT                                                             
  - SleepQuality: GOOD / NORMAL / BAD

  Journal API 명세

  Base path: /api/v1/journals (전체 인증 필요)

  일지 조회/삭제

  ┌────────┬──────────────────────┬──────────────────────────┬────────────────────────────┐
  │ Method │         Path         │           설명           │            응답            │
  ├────────┼──────────────────────┼──────────────────────────┼────────────────────────────┤
  │ GET    │ /{date}              │ 특정 날짜 일지 상세 조회 │ 200 JournalDetailResponse  │
  ├────────┼──────────────────────┼──────────────────────────┼────────────────────────────┤
  │ GET    │ ?startDate=&endDate= │ 기간 내 일지 날짜 목록   │ 200 { dates: LocalDate[] } │
  ├────────┼──────────────────────┼──────────────────────────┼────────────────────────────┤
  │ DELETE │ /{date}              │ 특정 날짜 일지 전체 삭제 │ 200                        │
  ├────────┼──────────────────────┼──────────────────────────┼────────────────────────────┤
  │ DELETE │ ?startDate=&endDate= │ 기간 내 일지 전체 삭제   │ 200                        │
  └────────┴──────────────────────┴──────────────────────────┴────────────────────────────┘

  감정/증상

  ┌────────┬──────────────────────────────────────┬───────────────────────────────────────────┬─────────────────────────────────────────┐

  │ PATCH  │ /condition-tags/{tagId}/visible      │ —                                         │ 200 ConditionTagResponse (visible 토글) │
  ├────────┼──────────────────────────────────────┼───────────────────────────────────────────┼─────────────────────────────────────────┤
  │ POST   │ /conditions                          │ { tagId }                                 │ 201 ConditionCheckResponse              │
  ├────────┼──────────────────────────────────────┼───────────────────────────────────────────┼─────────────────────────────────────────┤
  │ DELETE │ /conditions?tagId=&date=             │ —                                         │ 204                                     │
  └────────┴──────────────────────────────────────┴───────────────────────────────────────────┴─────────────────────────────────────────┘
