# a.tune Design Guidelines

모든 화면에 공통 적용할 디자인 판단 기준을 정리한다. 특정 화면의 구현 설명이 아니라 새 화면에도 재사용 가능한 원칙만 남긴다.

구체적인 레이아웃 유형과 공통 UI 패턴은 [Patterns.md](./Patterns.md)를 따른다.

---

## Core Principles

- 한 화면의 주 행동은 하나만 강하게 강조한다.
- 검정 버튼은 사용자가 지금 완료해야 하는 핵심 CTA에만 사용한다.
- 보조 행동은 텍스트 링크, 연한 버튼, 아이콘 버튼으로 낮춘다.
- 입력 화면, 상태 화면, 완료 화면은 레이아웃 역할을 분리한다.
- 같은 성격의 화면은 같은 시작점, 같은 버튼 높이, 같은 입력창 구조를 사용한다.
- 명백한 설명 문구는 제거하고, 상태와 대상 정보만 남긴다.
- 텍스트 계층은 크기, 굵기, 색상 중 최소 2개 이상으로 분명하게 나눈다. 2px 차이는 계층이 아니다.
- 모든 화면은 Practical UI와 Refactoring UI의 기본 원칙을 위반하지 않는다.
- 공통 컴포넌트가 있는 UI는 화면별로 재정의하지 않고 공통 프리셋을 따른다.

---

## Typography

- 기본 폰트는 `NanumSquare`를 사용한다.
- 상단 타이틀은 `text-sm font-bold`를 기본으로 한다.
- 보조 설명은 `text-xs text-gray-600 leading-relaxed` 또는 `text-gray-500` 계열로 낮춘다.
- 상태 화면의 대상 정보는 `text-xl font-semibold text-gray-900`처럼 명확하게 강조한다.
- letter spacing은 기본값을 유지하고, 장식적 타이포그래피를 피한다.

---

## Visual System

- 화면 배경은 `bg-gray-50`을 기본으로 한다.
- 정보성 카드는 흰색 배경, 테두리, 충분한 그림자로 배경과 분리한다.
- 액션 또는 강조 카드는 옅은 보라 배경과 약한 그림자를 사용한다.
- 배경색만으로 카드를 구분하지 않는다. 색상, 그림자, 테두리를 함께 사용한다.
- 보조 텍스트는 `text-gray-500` 또는 `text-gray-600`을 사용한다.
- 구분선은 매우 연하게 사용한다.
- 브랜드 감성이 필요한 시작 화면에서만 넓은 보라 배경을 사용한다.

---

## Content Rules

- 당연한 설명은 제거한다.
- 제목과 설명에서 같은 의미를 반복하지 않는다.
- 한 화면 안에서 진한 텍스트가 연속으로 경쟁하지 않게 한다.
- 버튼 문구는 행동 중심으로 쓴다.
- 링크는 실제 이동 또는 재요청이 있는 항목에만 사용한다.
- 목표와 가이드라인은 측정 가능하고 구체적인 문장으로 작성한다.
- "요즘"처럼 시간 범위를 좁히는 표현은 신중히 사용한다. 과거 경험과 충돌할 수 있다.

---

## Consistency Checklist

- [ ] 주 행동이 하나만 강하게 강조되는가?
- [ ] 보조 행동이 primary CTA와 경쟁하지 않는가?
- [ ] 공통 컴포넌트 프리셋을 불필요하게 덮어쓰지 않았는가?
- [ ] 레이아웃 유형과 컴포넌트 패턴의 역할이 섞이지 않았는가?
- [ ] 텍스트 계층과 카드 구분이 충분히 분명한가?
- [ ] 불필요하거나 반복되는 설명 문구를 제거했는가?
- [ ] Practical UI와 Refactoring UI의 기본 원칙을 위반하지 않는가?
