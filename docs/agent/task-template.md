```markdown
- 관련 도메인: (예: journal, medication)
- 관련 코드: (파일 경로)
- 관련 문서: (docs/... 링크)

### 변경 내용
- 

### 검증
- [ ] pnpm typecheck
- [ ] pnpm build
- [ ] 관련 문서 갱신
- [ ] 아키텍처 규칙 확인

### 위험 / 메모
- ASSUMPTION:
- TODO(owner, date, reason):
```
