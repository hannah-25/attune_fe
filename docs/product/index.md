# 제품 개요

## 목적

a.tune은 ADHD 환자가 **약물 복용을 추적**하고 **일상 상태를 일지로 기록**하여,
자신의 패턴을 이해하고 진료/상담에 활용하도록 돕는 모바일 웹앱(PWA)이다.

## 주요 사용자

- ADHD 약물을 복용 중이며 복용 습관과 컨디션 변화를 추적하려는 개인
- (보조) 기록을 바탕으로 상담을 준비하려는 사용자
- ASSUMPTION: 관리자(admin) 화면은 운영진용. 상세 권한 정책은 [security-rules](../architecture/security-rules.md) 참고.

## 핵심 기능

- **약물(medication)**: 약 목록/추가/정보/알람/복용 이력, 복용 분석
- **일지(journal)**: 전체 입력(태그+목표 슬라이더+메모), 타임라인, 캘린더, 태그 관리
- **홈(home)**: 오늘 요약 리스트 / 캘린더 뷰
- **캘린더(calendar)**: 일정, 이벤트 상세/추가, 외부(구글) 캘린더 연동
- **리포트(report)**: 주간/월간 리포트
- **상담(counseling)**: 상담 목록/준비/결과
- **커뮤니티(community)**: 피드, 글 상세/작성
- **온보딩(onboarding)**: 1~5단계 + AI 추천(감정·컨디션 태그)
- **설정(settings)**: 마이페이지, 알림, 탈퇴
- **게스트 모드 / 오프라인-퍼스트**: 비로그인·오프라인에서도 핵심 흐름 사용 가능

세부 도메인 규칙: [domain-overview](domain-overview.md).
